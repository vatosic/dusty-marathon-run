# DUSTY Marathon Run — версия 2

Проект разделён на две части.

## Часть 1. Дизайн и графика — `part1-design-graphics/`
- `index.template.html` — разметка и стили интерфейса (HUD, кнопки, экраны старта, паузы и финиша).
- `render3d.js` — основной 3D-рендер на Three.js (WebGL): камера, свет и тени, герой, соперники, предметы, препятствия, эффекты, имена над бегунами.
- `characters.js` — объёмные фигуры со скелетом (таз, корпус, плечи, локти, бёдра, колени, голеностопы), беговой цикл и позы болельщиков; толпа рисуется через InstancedMesh; собака.
- `world3d.js` — набережная: дорога, гранитный парапет, река, мосты с арками, здания с окнами (шейдер), деревья, фонари, Кремлёвская стена, ориентиры, точка Дасти, небо.
- `textures.js` — процедурные текстуры: майка героя (развёртка вокруг корпуса), асфальт, плитка, гранит, вода, баннеры.
- `render2d.js` — упрощённая 2D-графика на случай, если WebGL недоступен.

## Часть 2. Технология и логика — `part2-logic-tech/`
- `data.js` — маршрут, районы, константы времени и рекорд-лимита, импорт участников (CSV/JSON).
- `sim.js` — правила: скорость, каденс, «форма», ресурсы, пульс, предметы, препятствия, столкновения с бегунами, время и результат. Без DOM, проверяется в Node.
- `audio.js` — синтезированные звуки и ритм точки Дасти (Web Audio).
- `main.js` — игровой цикл, управление (тап = прыжок, свайпы, клавиатура), HUD, пауза, экраны.
- `club.js` — встроенный список соперников: 100 участников клуба (только имена). Пересобирается из выгрузки заказов DDLONG:
  `python3 part2-logic-tech/club_roster.py выгрузка.xlsx`. Саму выгрузку в репозиторий не кладём.

## Соперники и звёзды бега
По умолчанию на трассе 100 участников клуба «Пыльные Гантели». Старт общий: все стоят на всю ширину дороги перед аркой, впереди звёзды.
Клуб финиширует равномерно от 2:30:00 до 4:00:00 (кому какое время — случайно в каждом забеге), всё быстрее — звёзды.
На стартовом экране можно загрузить свою выгрузку посещений или включить демо-список вымышленных прозвищ.
20 звёзд бега России (`D.STARS` в `data.js`, подписи — по открытым источникам) бегут быстрее 2:30:
их можно обогнать, но в место и итоговое время они не входят.

После старта все соперники сбегают на свою дорожку слева и на три полосы игрока не заступают. На их дорожку можно
уйти и самому: там нет ништяков и препятствий, зато много бегунов. `?lane=3` в адресе — прежний режим, где соперники бегут
по полосам игрока.

## Время и правила
Секунда игры = минута марафона (4:04 игры → 4:04:00). Итог = время × 60 + штрафы − бонусы,
но не быстрее 2:00:00 (`D.RECORD_SEC` в `data.js`). Скорость задаёт каденс 160…200: гель действует 20 с, питьё 25 с,
еда 30 с; каждый пустой запас — каденс −10 (крупное предупреждение за 5 с), бустеры дают 5 с на каденсе 210. Лужа сбивает
каденс на 10, фан-барьер, собака, фотограф, самокатчик и волонтёр — на 50 на 3 с. Гелей, питья и еды на трассе вдвое
больше, чем нужно на идеальные 2:00. Без управления марафон дольше 4:00:00.

## Трасса
Набережные от Краснопресненской до Кремля: у каждого района свой стиль застройки (сталинки, доходные дома, кирпичные
фабрики, стекло, панельки), ориентиры — объёмные модели. В Лужниках — беговое покрытие, каждые 5 км — арка и сплит,
на 11, 24 и 33,5 км — рейв поддержки Дасти, на главной точке играет DJ KIM. В Лужниках вся правая сторона — зона
поддержки: сцены с диджеями, светомузыка и танцпол, играет техно. Всю дистанцию слышны шаги, дыхание и болельщики.

## Сборка и проверка
`./build.sh` → `dist/index.html`. Three.js подключается с cdn.jsdelivr.net (three@0.149.0).
`node test/test.js` — правила и прогон дистанции ботами. `test/*.py` — проверки в браузере (Playwright).

## Публикация через GitHub Pages
В репозитории есть `.github/workflows/pages.yml`: при каждом пуше в `main` он прогоняет `node test/test.js`,
собирает игру и выкладывает `dist/` на GitHub Pages. В pull request'ах в `main` — только тесты и сборка, без публикации. Один раз включите в настройках репозитория
Settings → Pages → Source: **GitHub Actions**.

## Локальная проверка в браузере
```
npm install            # ставит three@0.149.0 для офлайн-проверок
pip install playwright && python3 -m playwright install chromium
npm run test:browser
```
Скриншоты сохраняются в `shots/` (папка в .gitignore).
