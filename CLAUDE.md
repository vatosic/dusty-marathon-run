# CLAUDE.md — контекст проекта DUSTY Marathon Run

Браузерная 3D-аркада для бегового клуба «Пыльные Гантели» (Dusty Dumbbells Anonymous Running Club, est. 2019).
Марафон 42,195 км по московским набережным от Краснопресненской до Кремля. Язык интерфейса и общения — русский.
Игра опубликована на GitHub Pages: https://vatosic.github.io/dusty-marathon-run/

## Структура (две части — так попросил заказчик)
- `part1-design-graphics/` — дизайн и графика: `render3d.js` (Three.js r149, камера, свет, тени, пулы объектов, 2D-слой с именами),
  `characters.js` (скелет бегуна, беговой цикл, позы болельщиков, толпа на InstancedMesh, собака), `world3d.js` (набережная, мосты,
  здания с окнами в шейдере, Кремль, ориентиры, точка Дасти, небо), `textures.js` (процедурные текстуры, майка героя),
  `render2d.js` (резервная 2D-графика без WebGL), `index.template.html` (разметка и стили).
- `part2-logic-tech/` — технология и логика: `data.js` (маршрут, районы, константы, импорт участников), `sim.js` (все правила,
  без DOM), `audio.js` (Web Audio), `main.js` (игровой цикл, ввод, HUD, экраны).
- `build.sh` склеивает всё в один файл `dist/index.html`. Three.js грузится с cdn.jsdelivr.net (three@0.149.0, UMD).
- `.github/workflows/pages.yml` — при пуше в `main`: `node test/test.js` → сборка → публикация `dist/` на GitHub Pages.

## Команды
- `sh build.sh` — собрать. После любых правок в `part1`/`part2` пересобрать и закоммитить `dist/index.html`.
- `node test/test.js` — проверка правил и прогон всей дистанции ботами (идеальный, средний, пассивный). Должно быть 0 провалов.
- `npm install && python3 test/browser3d.py 390x844` — проверка в браузере (Playwright), скриншоты в `shots/`.

## Ключевые правила игры (не ломать без запроса)
- Время: 1 секунда игры = 1 минута марафона (`TIME_SCALE = 60`). 4:04 игры → 4:04:00.
- Итог = время × 60 + штрафы − бонусы, но не быстрее `RECORD_SEC = 2:00:00` (рекорд-лимит по просьбе заказчика).
  Идеальный забег ≈ 2:00. Калибровка ботами: почти идеальный 2:10–2:18, средний ~2:30, без управления 3:15–4:15.
- Скорость = база × каденс × «форма» (каждый ресурс > 60% даёт +5%) × кофеин 1,35 × замедление 0,68 × штраф за ресурсы < 25%.
- Ресурсы: энергия, калории, вода, пульс; предупреждения появляются < 25%, исчезают > 40%.
- Предметы и препятствия, их баланс — в `D.ITEMS` и `D.OBST` (`sim.js`). Столкновение с бегуном: +4 с, замедление 1,5 с.
- Механики открываются по км: магний, фотографы, собаки — с 5 км; «дай пять» — с 10 км; точка Дасти с диджеем — 24 км.
- Генерация трассы всегда оставляет проходимую полосу (проверяется в тестах).
- Управление: тап по полю = прыжок, свайпы = полосы, кнопки ◀ ▶ / прыжок / каденс ±; клавиатура ← → пробел + − P M.
- Звук по умолчанию выключен, музыка — только оригинальный синтез.

## Участники
- Импорт CSV/JSON: `id, name, club, long_runs_attended` или `user_id, name, club, event_id, attended`.
  Фильтр клуба «Пыльные Гантели» / «Dusty Dumbbells», объединение по ID, топ-100 по посещённым лонгам, при равенстве — по ID.
- Без файла — демо-список вымышленных прозвищ. Никогда не выдавать его за реальный рейтинг, не придумывать реальных людей,
  не хранить телефоны и почту.

## Принципы работы
- Не заявлять, что что-то протестировано на устройстве, подключено к сайту клуба или опубликовано, если этого не было.
- Трасса — художественная адаптация, не GPS-копия.
- Фото героя от заказчика так и не пришло: внешний вид — по описанию (розовая кепка, чёрные шорты, розовая майка
  с фиолетовыми пятнами и салатовыми элементами, на спине «DUSTY DUMBBELLS ANONYMOUS RUNNING CLUB», знак, «est. 2019»).
- Пожелание заказчика по графике: фигуры реалистичнее, «как в Zwift». Следующий шаг — glTF-модели вместо примитивов, если появятся.
- Известный долг: в `pages.yml` действия `@v4` на Node.js 20 — обновить, когда GitHub начнёт требовать.
